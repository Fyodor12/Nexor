# Nexora — публикация через GitHub Pages

1. Распакуйте ZIP.
2. В GitHub откройте репозиторий `Nexora`.
3. Выберите **Add file → Upload files**.
4. Загрузите `index.html` и `style.css` (и этот GUIDE.md при желании).
5. Нажмите **Commit changes**.
6. Откройте **Settings → Pages**.
7. В разделе Build and deployment выберите **Deploy from a branch**, ветку `main`, папку `/ (root)`, затем Save.
8. Через несколько минут сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/Nexora/`.

Примечание: это базовая статическая версия. Для автоматической публикации новых статей из ChatGPT потребуется отдельно настроить безопасную интеграцию записи в репозиторий.
